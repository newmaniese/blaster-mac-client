On connect

Commands run when the client connects. Delay is seconds to wait before each command.

On disconnect

After BLE disconnect, the ESP32 runs this command following Delay seconds. Reconnect cancels the countdown.

Active (cam/mic on)

Idle (after cooldown)

First row’s Delay is the cooldown (seconds both cam and mic must stay off) before Idle commands run. Later rows’ Delay is wait before that command.
