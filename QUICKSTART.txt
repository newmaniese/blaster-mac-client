Blaster Mac Client — run on this Mac
====================================

1. Download blaster-mac-client.zip from:
   https://github.com/newmaniese/blaster-mac-client/releases

2. Unzip the folder anywhere (Downloads is fine).

3. Open Terminal (Applications → Utilities → Terminal).

4. Go into the folder:
   cd blaster-mac-client

5. Set ble.auth_token in config.yaml to the same BLE_AUTH_TOKEN as the firmware
   (16–64 characters). You can also set it later in the management UI.

6. Install it to run at login:
   chmod +x install.sh && ./install.sh

   This copies the app to:
     ~/Library/Application Support/blaster-mac-client
   installs dependencies, and starts it. It starts automatically when you
   log in and restarts if it crashes. No Full Disk Access needed.

   Management UI: http://127.0.0.1:8765
     • Status (connection, cam/mic, last command)
     • Reconnect and send saved IR commands
     • Edit device name, BLE auth token, and OnConnect / OnDisconnect /
       Active / Idle, then Save & apply

   Logs: ~/Library/Logs/blaster-mac-client/blaster.log (rotated)
   Debug: BLASTER_LOG_LEVEL=DEBUG or python -m blaster --log-level DEBUG

   After installing, you can delete this unzipped folder.

To remove: ./uninstall.sh   (or, if you deleted this folder:
   launchctl unload ~/Library/LaunchAgents/com.blaster-mac-client.plist
   rm -rf ~/Library/LaunchAgents/com.blaster-mac-client.plist
   rm -rf "$HOME/Library/Application Support/blaster-mac-client")

Just want to try it once, without installing?
   chmod +x run.sh && ./run.sh      (Ctrl+C to stop)

Requirements: macOS with Bluetooth; IR Blaster powered and in range. Device
name in config must match firmware BLE_DEVICE_NAME, and ble.auth_token must
match firmware BLE_AUTH_TOKEN.
